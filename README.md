# Propostes de llibre d’estil

Prototip visual amb tres propostes de sistema gràfic per al pilotatge dels mòduls 1 i 2.

## Contingut

- `index.html`: pàgina inicial de selecció.
- `01_savia_petroli.html`: proposta Sàlvia i petroli.
- `02_blau_coral.html`: proposta Blau tinta i coral.
- `03_pruna_verd.html`: proposta Pruna i verd mineral.

El projecte és HTML i CSS estàtic i es pot publicar directament amb GitHub Pages.
